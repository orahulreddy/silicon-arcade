# 🕹️ Silicon Arcade

An interactive retro-tech arcade, Web Audio experiments, and micro-tools hub running live at [siliconarcade.in](https://siliconarcade.in).

## ✨ Features & Mini-Games
- **Neon Pong:** Canvas 2D paddle engine with adaptive AI tracking and synthetic Web Audio.
- **Cyber Snake:** Grid-based arcade game with swipe/keyboard inputs and high score tracking.
- **Neural Matrix:** Interactive particle node sandbox with cursor gravity and multiple neon palettes.
- **Curated Gallery:** Embedded PICO-8 retro cart viewer and open-source emulator showcase.
- **The Ledger:** System logs covering web performance, hardware silicon, and handheld emulation.

## 🚀 Tech Stack
- Pure HTML5, CSS (Tailwind CSS CDN), and Vanilla JavaScript (Canvas 2D / Web Audio API)
- Zero build tools or heavy framework dependencies
- Deployed globally on [Vercel](https://vercel.com)
